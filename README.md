## Upload
1. Create a new GitHub wedding-invitesitory (public, e.g. `wedding`).
2. Upload the *contents* of this folder (the 7 folders and `music.mp3`), so `music.mp3` is at the top of the wedding-invite.
3. Settings > Pages > Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`. Save.
4. After a minute or two the links above go live.

Keep the trailing `/` on each link. The pages are marked "noindex" so search engines won't list them.
